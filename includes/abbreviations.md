*[GeoTIFF]: An image file (.tif) with embedded geographic information, so GIS software can place it on a map.
*[GeoTIFFs]: Image files (.tif) with embedded geographic information, so GIS software can place them on a map.
*[CRS]: Coordinate Reference System: the framework that defines where on Earth an image is located.
*[NIR]: Near-infrared light, just beyond what humans can see. Useful for detecting vegetation.
*[RPAS]: Remotely Piloted Aircraft System, i.e. a drone.
*[ONNX]: Open Neural Network Exchange, a portable format for machine learning models.
*[GDAL]: Geospatial Data Abstraction Library, the open-source library most GIS software uses to read rasters.
*[CUDA]: NVIDIA's GPU computing platform. A CUDA-capable GPU speeds up processing.
*[GPU]: Graphics Processing Unit. Optional, but makes processing much faster.
*[IoU]: Intersection over Union, a measure of how well predicted and hand-labelled areas overlap.
*[L2A]: Sentinel-2 Level-2A: atmospherically corrected surface reflectance imagery.
*[uint8]: Unsigned 8-bit integer pixels, with values 0–255.
*[uint16]: Unsigned 16-bit integer pixels, with values 0–65535.
